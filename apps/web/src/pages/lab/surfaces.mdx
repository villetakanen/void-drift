# Surfaces

Cut panels frame menus and flight status, instrument surfaces distinguish displays from the console, and the dialog scrim dims the stage behind a dialog.

## Menu panel and flight status

Use `.panel` for a menu or dialog. Add `.panel--flat` for a status message over live flight: it keeps the same fill and cut edge, but removes the shadow and uses less padding.

## Classes and tokens

| Class or token | Use |
| --- | --- |
| `.cut-surface` | Glass fill and 1px `--color-border` edge that follows the cut. Defaults to the medium cut, with no shadow. |
| `.panel`, `.panel--flat` | Both use `--panel-fill` (elevation 2) and the large cut. Only the standard panel uses `--panel-shadow`. |
| `--cut-size-sm`, `--cut-size-md`, `--cut-size-lg` | `6px` for small controls, `10px` for buttons and segmented controls, `16px` for panels. |
| `--color-void`, `--color-elev-1` through `--color-elev-3` | Background, console, display and overlay pane, in order of increasing lightness. |
| `--surface-display`, `--shadow-display` | Instrument display background, bezel and shadow. |
| `--color-backdrop` | Black at 11% for Lab overlay panes. |
| `.scrim-stage` | Dims, blurs and tints an opaque stage using `--scrim-filter` and `--scrim-tint`. |
| `.dialog-scrim` | Adds scanlines, darkened edges and a screen blend over the stage using `--scrim-surface` and elevation 2. Neither scrim class makes the stage inert. |

## Layer order

Use layer tokens for shared `z-index` values. To put a fill behind its label without moving the whole control, isolate the control and use `--layer-under` on the fill.

| Token | Value | Use |
| --- | --- | --- |
| `--layer-toast` | `200` | Status messages above other UI. |
| `--layer-overlay` | `100` | Dialogs and their scrim. |
| `--layer-hud` | `10` | Deck instruments and controls. |
| `--layer-raised` | `1` | Sticky footers and Lab panes above their backdrops. |
| `--layer-base` | `0` | Stage and page content. |
| `--layer-under` | `-1` | Behind content within an isolated component. |
