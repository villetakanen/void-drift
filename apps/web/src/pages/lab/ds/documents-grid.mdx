## Width and classes

- `.documents-grid` fills its parent and measures that width, not the viewport.
- `.documents-grid__content` adds 16px padding on every side and a 16px gap between items or tracks. It stacks children in source order until there is room for 67ch of prose, a smaller golden-section gutter (`67ch / φ`, about 41.4ch), and 64px for the two side padding edges and two column gaps. The outside column takes whatever width remains.

## Authoring

Use `<DesignSystemLayout title="…" documentProse>` for an MDX reference. The layout supplies both grid wrappers; `documentProse` opts into shared typography.

Write Markdown directly inside the layout. Put an `<aside>` immediately after the paragraph it supports, as a direct sibling, so it can share that paragraph's row when wide. Don't wrap them together in a `div`: the grid would place the wrapper across all columns instead of placing the two blocks separately. The Design system layout supplies the aside's panel appearance; the grid only places it.
