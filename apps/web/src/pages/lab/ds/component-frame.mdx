# Component frame

Shows a component's own box and spacing, isolated from the page around it.

## Default

The frame fills its parent's width. The grey block has a margin, so the gap between it and the dashed line is the block's own.

<ComponentFrame>
  <div className="frame-sample">Margin 16px · padding 8px 16px</div>
</ComponentFrame>

## Fit

With `fit`, the frame takes the width of its content.

<ComponentFrame fit>
  <div className="frame-sample">Margin 16px · padding 8px 16px</div>
</ComponentFrame>

## Usage

- Use the default for a component that adapts to the width it is given. It is the named `component-frame` inline-size container.
- Use `fit` for a component with a width of its own, so the line shows that width. A `fit` frame is not a size container.
- The frame adds no padding, margin or background. The page owns the space around it.
- The frame is not a stage for host surfaces and not a separator between examples and text.
