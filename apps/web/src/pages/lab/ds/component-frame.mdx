## Component frame

Marks the boundary of a live component example.

<ComponentFrame><span>Example content</span></ComponentFrame>

The dashed line and padding separate the example from its documentation.
The frame fills its parent and leaves the page background visible.

### Spacing

Padding follows the [shared spacing grid](/lab/tokens), whose base unit is
`--spacing-xs`. Horizontal padding is twice the vertical padding.

| Direction | Base grid units | Token |
| --- | --- | --- |
| Top and bottom | 2 × | `--spacing-sm` |
| Left and right | 4 × | `--spacing-md` |

### Usage

Place example content inside `ComponentFrame`. Svelte receives it as a `children`
snippet; Astro and MDX pass it as nested content.

The frame provides the named `component-frame` inline-size container for
components that adapt to available width. Its parent sets that width.
