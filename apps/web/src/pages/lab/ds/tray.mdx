## Anatomy

Overview is an ordinary first link. Noninteractive group headers introduce lists
of destination links; their smaller, muted type and larger inter-group gap keep
the hierarchy quiet. The example's Structure and Controls groups illustrate
anatomy, not a required taxonomy for live navigation.

The header and logo stay outside the tray, above it. This reference does not
change header geometry, workspace switching, destination membership or live
tray scrolling. The example is 256px wide, not a shared sizing API.

## States and accessibility

Resting links use neutral text on the base surface. The current page uses
selected-colour text and a single leading edge, with `aria-current="page"`.
Hover adds a light surface wash without replacing the selected cue.

Every destination is a native link, reachable in document order with Tab and
activated with Enter. Keyboard focus adds a separate inset outline, including
on the current page. Group headings are not controls or tab stops. Rows retain
a 44px minimum target height. Try focusing Overview and Tray in the example.
