## Anatomy

Overview is an ordinary first link. Noninteractive group headers introduce lists
of destination links; their smaller, muted type and larger inter-group gap keep
the hierarchy quiet. The example's Structure and Controls groups illustrate
anatomy, not a required taxonomy for live navigation.

The header and logo stay outside the tray, above it. The Design system layout
owns the 250px independently scrolling rail; this example is 256px wide where
the frame allows it.

## States and accessibility

Resting links use neutral text on the base surface. The current page uses
selected-colour text and a single leading edge, with `aria-current="page"`.
Hover adds a light surface wash without replacing the selected cue.

Every destination is a native link, reachable in document order with Tab and
activated with Enter. Keyboard focus adds a separate inset outline, including
on the current page. Group headings are not controls or tab stops. Rows retain
a 44px minimum target height. Try focusing Overview and Tray in the example.

## Inputs and host responsibilities

`apps/web/src/components/Tray.svelte` renders native links on the server without
hydration. Its typed inputs are:

| Input | Purpose |
| --- | --- |
| `label` | Accessible label for the navigation landmark. |
| `links` | Ordered leading destinations, each with `label` and `href`. |
| `groups` | Ordered groups, each with a `label` and ordered `links`. |
| `footerLinks` | Optional ordered destinations after the groups. |
| `activeHref` | Host-resolved href (or `undefined`); the matching link gets `aria-current="page"`. |

The host owns routing, destination order, sizing and scrolling. The live layout
selects the deepest matching destination from the Design system registry,
including pages at earlier addresses such as `/lab/tokens`. The example supplies
Tray as its current destination.

The contract at `docs/specs/factory/design-system/tray/spec.md` governs the
shared component. Its neutral resting-link exception covers only the live
Design system rail and this example; Lab, Design studies and the game retain
their own navigation.
