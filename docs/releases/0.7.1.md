# 0.7.1 — Fires in the Sky

Patch release for Fires in the Sky. Ranked Survival pirates now wrap at the
world boundary and remain the same live encounter. Only destruction starts the
seeded 45–60 gameplay second replacement wait; wrapping awards no destruction
points. Derelict departure behavior is unchanged. All four workspace packages
are versioned 0.7.1.

The release also includes the current Lab and design-system work: shared page
headers, instrument side sheets and catalog updates, with related study and
specification changes.

## Ranked compatibility

The baseline is the last published release, [0.7.0](0.7.0.md), tag `v0.7.0` at
`7ba2c76e93b622c618bfc62bb0a3343e94f20ab4`, which uses `fires-in-the-sky`.
This patch corrects ranked pirate boundary handling within the approved rules.
By the owner's release decision, ranked Survival remains on the existing
`fires-in-the-sky` challenge and leaderboard; the challenge code and Firestore
rules are unchanged.
