# 0.6.3 — Settings in the game menu

Settings reuses the game scene, scrim and menu panel, with shared Switches,
keyboard-accessible descriptions and persistent device preferences. Speed camera
is an optional device preference. The world HUD gains consistent body identities;
planet drawing shares ordered passes and skips offscreen work. Practice carries
the Mercury and Venus rendering work, while the Lab adds the planet inspector,
flight-scene capabilities and design explorations.

## Ranked compatibility

The comparison baseline is the published 0.6.2 release, tag `v0.6.2` at
`b31e1f42f9528a141cc5b7a8bb4dadad81d636ed`. Ranked Survival retains the legacy
Sun, stock planet masses, physical rules, scoring and catalog eligibility. The
new stellar profile applies to Playground Survival, which remains unranked;
Mercury and Venus changes apply to Practice. Camera, HUD and rendering changes
are presentation and do not change simulation inputs or score calculation.
Firestore retains the same `ion-storm` write rule.

A direct comparison of the old and candidate simulations covered 96 scripted
runs and 345,600 ticks: three scored starter ships and their stock profiles,
four seeds and four input patterns. Physical state, survival status, elapsed time,
wraps, resources, encounter state and scores were identical at every compared
tick. Display identities and visual ring metadata were excluded. This bounded
comparison supports the source review; it is not an exhaustive proof of every
possible fitting or input sequence.

The challenge remains `ion-storm`; existing scores remain comparable and the
board remains open. All workspace packages are versioned 0.6.3.
