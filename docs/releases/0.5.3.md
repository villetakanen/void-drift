# 0.5.3 — Gravity and Lab consolidation

Locally verified and prepared on 5 November 2026. Not pushed, tagged, published,
or deployed. The last recorded deployment remains 0.5.2; it was not rechecked live
in this consolidation.

## Changes

- The game's sun and planets use the committed mass-law gravity implementation,
  with physical bodies and a pull cut-off. The shared Gravity tuning bench compares
  four fitted ships and their no-well reference paths using production functions.
- The Lab index and navigation use one page registry with grouping and source labels.
  Ship tuning and Gravity tuning share the explicitly named Motion instrument.
- Ranked runs use `gravity-2`, separating the new rules from previous results.
  Previous score documents and legacy-client rule support remain intact.
- All four package versions are 0.5.3. Release cleanup repairs formatting and test
  fixtures without changing game physics or tuning values or adding dependencies.
- Plans now distinguish completed work, deferred proposals and unfinished trials.

The reviewed Motion instrument conformance contract is not fully implemented. Its
attempted migration was undone at the owner's request and is deferred from this
release. Existing per-vehicle property overrides and import controls remain; new
acceptance criteria stay unchecked. The uncommitted ship-motion study, capture,
investigation notes and directional-speed engine experiment remain in the original
checkout and are excluded. Camera trial 2 remains unmerged in its own worktree.
See [the current work map](../plans/2026-11-05-release-0.5.3.md).
