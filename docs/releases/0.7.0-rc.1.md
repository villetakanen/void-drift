# 0.7.0-rc.1 — Fires in the Sky

This release candidate starts the `fires-in-the-sky` ranked challenge on its own
leaderboard. Its ranked rules are incompatible with the published `ion-storm`
challenge, whose existing board and client write support remain separate.
All workspace packages are versioned 0.7.0-rc.1.

Survival, Derelicts and Gauntlet use the same seed-selected yellow-family G
star and a seeded 16–36u mercurial planet replacing the stock innermost body.
Other stock planets remain when their circular paths are clear of it. The seed
sets retained planets' initial orbital phase. Mercurial mass follows the shared
core-led profile, calibrated to Practice Mercury's mass 870 at radius 27u. This candidate includes that system profile in ranked Survival.

Plasma engines and plasma weapons remain future scope for the final 0.7 release.

This candidate is for review and has not been published to production.
