# 0.5.1 — Fiddler and factory refinement

Version 0.5.1 adds the connected Fiddler ship-construction study and refines the
development factory around that work.

## Changes

- The Fiddler study connects capacity, engine placement, pincer slots, stabilizers
  and window placement to the shared ship-building systems.
- The factory guidance and living design-study contract now separate study
  procedure, output requirements and optional quality evaluation. Failed studies
  remain valid project outcomes, with their assessment preserved.
- Verification coverage is pruned around behavioral contracts and integrated
  journeys. Full verification shares one Firebase emulator lifecycle, while review
  captures run separately from correctness checks.
- All workspace packages are versioned 0.5.1. No dependencies or gameplay physics
  constants changed.

## Release evidence

Full verification passed on unchanged source in
`artifacts/verification/2026-11-03T16-03-07.343Z-2eBzth/report.json` with no skipped
stages. It covered contracts, commit syntax, lint, types, unit tests, production
