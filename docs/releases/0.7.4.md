# 0.7.4 — Fires in the Sky

Void Drift now reports unexpected browser errors and failures connecting to,
loading or saving shared scores to Sentry, helping diagnose problems players
encounter. [Browser error reporting](../specs/factory/browser-error-reporting/spec.md)
covers what is collected. All four workspace packages are versioned 0.7.4.

## Ranked compatibility

Compared with [0.7.3](0.7.3.md), this release adds diagnostics for browser and
Firebase errors. Ranked Survival trajectories, survival conditions, scoring and
eligibility are unchanged. Existing scores stay on `fires-in-the-sky`.
