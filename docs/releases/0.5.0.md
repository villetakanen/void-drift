# 0.5.0 — Arcade effects alpha

Release candidate, 3 November 2026. Publication and final verification are recorded
below when completed. The owner authorized all reviewed checkout changes for this
major alpha milestone; the version is 0.5.0.

## Changes

- A shared direct Canvas FX pass draws sharp engine beams, world-space trails,
  gravity arcs and bounded sparks above the world and ships. It replaces the costly
  offscreen blur/blend path; gameplay remains authoritative.
- `/lab/fx` exercises six real ship simulations, 24 main engines, 12 collectors,
  two station effects, 16 missile trails and 12 fire emitters at 1920×1080. Pause,
  reset, burst, overload and presentation-off controls make it inspectable.
- New `fx-development` skill explains the model to future agents. The living FX
  spec separates behavioral contracts, performance evidence and human experience.
  Exact painter/pixel assertions are replaced by lifecycle, fitting, activity,
  bounded-work and simulation-isolation coverage with review captures.
- Integrated Hangar Plan/View framing and shared controls, linked aft engines,
  default-on stabilizers, Gravity coil fitting and collection, and mount-planner
  refinements. Existing saves retain explicit stabilizer choices; missing values
  default on, and linked engines defaults off. Ranked starter rules stay separate.
- Includes the concurrent square Switch commit `a1fb69b`, utility/gravity studies
  and references, the exploratory Fiddler page, Lab refinements, and documentation
  cleanup into living Hangar guidance and historical records. Open/stopped studies
  retain their own status; inclusion is not design acceptance.

## Verification

Targeted engine/collection/wrap, keyboard/touch, pause/replay and FX control checks
passed during implementation. The initial type error, stale Lab counter and hidden
historical painter slowdown were repaired before release checks. Integration also
fixed formatting and explicit label associations for shared Switch consumers.

First full run (`artifacts/verification/2026-11-03T12-14-05.598Z-MmG7UW/report.json`)
failed three of 36 browser tests; every other gate passed, including 144 unit tests,
Firestore rules and competition. Its source fingerprint remained unchanged. The
failures exposed an undefined optional saved value bound to Switch, an obsolete
label-text locator, and a click before the Lab pane had hydrated. The fixes retain
the optional save contract, use the accessible checkbox name, and keep the pane
opener disabled until it can handle interaction. No assertion timeout was increased.
Final candidate verification and the deployed revision follow below.
The slice plan is `docs/plans/2026-11-03-alpha-0.5.0.md`.

## Performance evidence

The corrected sustained mixed-scene profile uses six visible moving ships with
turns, release, collection and periodic bursts. The fixture repeats after eight
seconds and uses diagnostic lane wraps to keep all six ships visible. It changes no
production gravity/friction constants. Reports include update plus FX submission
(the update includes all six full simulations), frame intervals and Chromium traces.
The measurements are headless Chromium on this Mac; mobile results are viewport and
touch emulation on the same host, not measurements from a physical phone.

Final profile: `artifacts/fx-profile/2026-11-03T12-10-23.645Z/report.json`,
Apple M4 Max, macOS ARM64, Chromium 156.0.8078.4; five-second warmup and 60 seconds
per profile. Both runs were uninterrupted with no page errors. The instrument
samples rolling ten-second windows (early windows also contain warmup).

| Profile          | Display / canvas CSS size | Update + FX p50 range | p95 range  | Largest window maximum | Frame p95 / maximum |
| ---------------- | ------------------------- | --------------------- | ---------- | ---------------------- | ------------------- |
| Desktop          | 1280×720 / 965×544        | 0.6–0.8 ms            | 1.1–1.5 ms | 7.8 ms                 | 16.8 / 16.8 ms      |
| Mobile emulation | 844×390 / 529×298         | 0.6–0.8 ms            | 1.1–1.8 ms | 7.1 ms                 | 16.8 / 16.8 ms      |

Both use the 1920×1080 backing canvas. The final rolling p95 is 1.2 ms in both;
transient maxima above 3 ms remain visible in the report. Desktop trace RasterTask
p95/max is 0.060/1.892 ms; Paint is 0.066/0.147 ms; FunctionCall is 1.720/2.577 ms.
Mobile-emulated RasterTask is 0.068/0.087 ms, Paint 0.070/0.196 ms and FunctionCall
1.728/3.544 ms. These are individual trace events across overlapping threads,
including world/UI work; they cannot be added to claim isolated whole-pipeline FX
cost. CompositeLayers/DrawFrame events were unavailable in this headless trace. The first run
was rejected as final evidence because a development reload interrupted sampling
and some ships could leave the viewport. The corrected fixture was rerun.

## Remaining human review and limits

Physical mobile performance, isolated attributable GPU/compositor cost, and owner
judgment of sharpness, sparkle, interference, layering and fun remain open. These
are not automated passes. The full under-3-ms whole-pipeline acceptance remains open
until those measurements exist, even when CPU submission and frame pacing are good.

Stations, missiles and fires in the FX Lab are workload fixtures, not new combat
systems. The Hangar's small-sun test flight has no planets, so collector activity
is visible in planetary flight or the FX Lab. The Hangar spec separately records
remaining information/recovery and experience gaps. Custom survival stays unranked;
no production test score is submitted during release checks.
