The roadmap holds the current release direction. Dated plans capture how we
thought we might get there; check their age and the current specs before acting.
An unfinished item in an old plan is not automatically future release scope.
Release records establish what shipped; loop evidence records the work and its
verification. Neither turns a finding into a standing requirement.

The other documents at this level retain their existing subjects and history.
This index provides an entry point without moving or deleting them.
