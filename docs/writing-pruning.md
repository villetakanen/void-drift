# Writing pruning

Concrete examples of language drift to collect for a future technical-writer
agent or review loop. That loop does not exist yet. As examples accumulate,
use them to define its scope and review criteria; this document does not create
a standing workflow or an automated gate.

## 001 / Invented audience-benefit jargon

**Recorded:** 2026-11-02, extra-energy equipment design study,
`/lab/studies/energy-support-2026-11-02`, section 02.2.

The study introduced “the pilot’s benefit” and “What does this equipment give
the pilot?” as an organizing frame. Related prose included “carry more possibility
into the next encounter” and “latitude to commit, correct or escape.” The designer
identified this as drift and asked for the language to be erased from the study.

The task was to establish the device’s function, name and characteristics:
something that stores and releases immense amounts of energy. The added rhetoric
shifted the discussion into an unrequested audience-benefit vocabulary and made
concrete equipment properties less direct.

| Prune                                             | Prefer in this context                                                         |
| ------------------------------------------------- | ------------------------------------------------------------------------------ |
| “What does this equipment give the pilot?”        | “What stores this much energy?”                                                |
| “Energy reserve names the pilot’s benefit.”       | Explain whether “reserve” implies shared capacity or a separate backup supply. |
| “Carry more possibility into the next encounter.” | “The device adds energy storage capacity.”                                     |

A future writing review should flag invented framing that has begun to sound
like agreed project terminology. Replace it with the actual function, property,
mechanism or unresolved question. Check the surrounding reasoning as well as
individual words: substituting “player” for “pilot” would leave this drift intact.

This example does not prohibit mentioning pilots when they are the actual subject.
It concerns an imposed rhetorical frame. Preserve explicitly adopted design
language, such as the support family’s “I create opportunities,” unless the designer
changes it. The speculative audience-benefit prose was not an adopted decision.
