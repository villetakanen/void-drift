# Factory building lessons

Numbered records of deliberate improvements to the Void Drift development factory.
These explain evidence, reasoning, adopted changes, and remaining validation; they
are not automatically instructions. Skills and specifications own active practice.
Numbering identifies factory improvements, not individual study attempts.

1. [001 — Modernizing the factory](001-modernizing-the-factory.md): traceable
   implementation, deterministic verification, and human experience review.
2. [002 — Phased design studies](002-phased-design-studies.md): purpose,
   exploration, integration, and cumulative human decisions throughout the work.

[Design-study evaluation protocol](design-study-evaluation.md) provides a bounded
replay for improvement 002. No comparative model evaluation has been run yet.
