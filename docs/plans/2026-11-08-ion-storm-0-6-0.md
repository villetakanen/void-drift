# 0.6.0 "The ion storm"

Scope stated in conversation on 8 November 2026, during the retrospective
[held the same day](../reviews/2026-11-08-retro-0-6-0/README.md). Status:
scope recorded; no slice started; no implementation authorized by this record.

## Goal

Polish the game to a state where all the basics are found: three stable ships,
a stable ion option for every basic ship part, scorable runs that should not
need their scores removed again, and the Hangar as the way to choose what you
fly.

## Stable set

The stable set is scorable. The intent is that scores from 0.6.0 remain valid;
whether `CHALLENGE` changes is decided at release preparation as usual.

| Part        | Stable options                                                                                 | State today                         |
| ----------- | ---------------------------------------------------------------------------------------------- | ----------------------------------- |
| Ships       | Wasp, Scout, Fighter                                                                           | exist; polish to scorable stability |
| Ship option | ion stabilizers                                                                                | exist                               |
| Engines     | light ion (`ion`), heavy ion (`heavy-ion`)                                                     | work                                |
| Weapons     | light ion cannon, rotating ion point-defence system                                            | cannon shipped in 0.5.6; PDS is new |
| Equipment   | Potential Well (`battery`), Heavy Potential Well (`heavy-well`), Gravity coil (`gravity-coil`) | exist                               |

Stabilizers are a ship option, not equipment. Ships have an inbuilt solar
collector; there is no slottable collector equipment yet. Everything else in
the catalogs (Corvette, Fiddler, `fusion`, `plasma`, `rail`, `laser`, the
Loading coil `coil`) is experimental.

## Rules

- A run flown with only stable ships, options and equipment is scored and
  leaderboard eligible.
- Using any experimental ship or part makes the run unscored for the
  leaderboard; the run still shows its score, as the
  [Hangar spec](../specs/game/hangar/spec.md) already states.
- The experimental state is visible on the front of the game before flight.

## Deliverables

1. **Rotating ion point-defence system.** The one new equipment of the release.
   Starts as a design study with a stated problem (decided 8 November 2026),
   then spec and implementation.
2. **Derelicts in the main game.** Bring derelicts from the derelicts mode into
   survival ([derelicts spec](../specs/game/derelicts/spec.md)).
3. **Hangar selects the ship.** The main screen shows the ship selected in the
   Hangar, including its equipment; the Hangar is where the player chooses a
   ship and fits it. Experimental parts enable the experimental ships and
   parts; the front of the game shows when a run will not be scored.
4. **Polish of the basic flows.** Title, Hangar, flight, death, scores. No
   list yet; collect from play.

## Out of scope unless separately decided

- Other stellar families ([follow-up study](2026-11-07-stellar-variety-follow-up.md)).
- Random star systems ([stub](random-star-systems.md)).
- Progression or economy for earning equipment.
- Slottable solar collector equipment.
