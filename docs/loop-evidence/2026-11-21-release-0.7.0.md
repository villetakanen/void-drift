# 0.7.0 release closure — 21 November 2026

## Intent and boundary

Publish 0.7.0 through a PR to `main`, complete full verification, deploy to Alpha,
verify the live site, tag the deployed revision, and return to `feat/0-7-0` with
`main` merged. The assigning session reports the user's authorization for these
steps and decision to use Fires in the Sky as the official challenge and continue
with 0.7 patches. Closure collects release evidence only.

ranked encounters and scoring, generated worlds and sky, Combat HUD and Settings
changes. It records the comparison with published 0.6.3 and the separate
`fires-in-the-sky` leaderboard while retaining `ion-storm` clients. The
[release procedure](../development.md#release) separates verification, preparation,
publication and live checks.
