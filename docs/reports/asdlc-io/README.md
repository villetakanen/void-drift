# ASDLC.io assessment through Void Drift

Status: planning and initial evidence reconnaissance, 12 November 2026. No assessment conclusions have been accepted yet.

This collection will assess ASDLC.io's agentic software development life cycle guidance through Void Drift and its design-led software factory. It covers the current factory and its documented evolution and decisions, producing evidence-backed findings and proposed documentation changes for later review at ASDLC.io.

Void Drift is the test subject. This work does not identify project improvement needs, propose project changes, or create a remediation backlog. It does not publish or send feedback externally.

The [execution plan](../../plans/2026-11-12-asdlc-assessment.md) defines the questions, stages, evidence standards, Luna High extraction workflow, review points and intended report files. The final evidence cutoff remains open while other sessions finish their closure records.

The completed collection will lead with how the factory works, compare relevant guidance against inspectable evidence, and develop framework findings and proposals. Source records will distinguish intent, implementation, execution evidence, recorded decisions and retrospective interpretation. A difference from a pattern is not automatically a defect, and a single project cannot establish universal effectiveness.
